# 导入运行手册

## 目的

本文档定义企业内网文件平台在首次一次性内容导入时的运维操作流程。

## 范围

- 个人空间导入准备
- 部门空间导入准备
- 公共知识库导入准备
- 导入执行前的校验要求

## 支持的文件类型

- `docx`
- `xlsx`
- `pptx`
- `pdf`
- `txt`
- `md`

## 文件约束

- 单文件最大 `10MB`
- 优先保留原始文件名
- 优先保留源文件的最后修改时间

## 推荐的准备目录结构

### 个人空间

```text
/import/personal/<username>/
```

### 部门空间

```text
/import/department/<department>/Collaboration Area/
/import/department/<department>/Publishing Area/
/import/department/<department>/Archive Area/
```

### 公共知识

```text
/import/public/<category>/
```

分类应与当前公共知识分类体系一致：

- Policies and Procedures
- Templates and Forms
- Training Materials
- Product Materials
- Project Cases
- FAQs

## 运维检查清单

1. 确认目标用户和部门已经在系统中存在。
2. 确认准备目录中的部门名称与系统中的目标部门一致。
3. 确认大于 `10MB` 的文件已被排除或拆分。
4. 确认不支持的文件格式已被排除。
5. 确认公共知识文件已映射到正确分类。
6. 确认公共知识条目已经有预期维护人和生效日期策略。
7. 确认旧来源文件在导入后的抽查完成前仍然保留。

## 当前 V1 的导入位置

当前仓库已经提供了准备目录规则、校验假设和公共知识元数据工作流。完整的自动化批量导入任务仍然属于后续加固项，因此当前 V1 的运维路径是：

1. 按要求准备目录结构。
2. 创建目标用户和部门。
3. 通过当前应用流程把文件上传或发布到正确的目标空间。
4. 在导入后对搜索、权限、回收站和版本行为进行抽样检查。

## 导入后验证

- 抽样验证个人文件只对所属用户可见。
- 抽样验证部门协作文件仅在预期位置可编辑。
- 抽样验证公共知识条目按预期元数据出现在公共知识列表中。
- 抽样验证导入文件能被搜索命中。
- 抽样验证导入文件的回收站和版本行为仍正常。
